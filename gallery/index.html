Step by step

不知道怎么选？问自己三句

这三句能定掉大部分选择，剩下的交给脚本。

01

最后交付的是什么？

  1. 会动的片子 → 视频（M1）
  2. 能点、能滚、给人用的页面 → 网页制品（M3）
  3. 点一下翻一页、我录屏 → 网页视频（M2）
  4. 一篇文章 / 一份文档 → 长文（M4）
  5. 一张图 → 静态图（M5）
  6. 只要一个动作的源码 → 动效素材（M6）
02

它要什么气质？

  • 往下到「风格族」，先看带真实案例帧的那些，最直观。
  • 有形容词也行：高级 / 赛博 / 中国风 / 复古 / 可爱 / 杂志 / 极简 / 数据感。
  • 拿不定主意就选 A（贴合），别在选风格上耗时间。
03

然后只要这一句

node scripts/do.mjs "<你要什么>"

它会建好 brief.md / NEXT.md / plan.json。判读不对就说「不对，我要的是网页制品」，或者加 --medium M3-web-artifact。

Real footage

真实样片

本仓库里能直接播的成片与动图。悬停自动播放，点开看全屏与文件路径。

Style atlas

风格族

同一套视觉规则在多个引擎里的实现放在一起。有图的是真实案例帧；没图的是按分类给的示意配色，不是原片。

Shot cards

镜头卡

做视频时的单镜头零件：每张卡是一个镜头的编排配方，带时长、能量与已知坑。

Motion verbs

动作语汇

单动作条目，可直接导出源码放进工程。这是「怎么动」，不是「长什么样」。
